## 系統簡介

員工日報回報系統讓員工每日記錄各類工項數量，管理者可進行確認、統計與薪資計算。系統分為兩個角色：

| 角色 | 說明 |
|------|------|
| **USER（一般使用者）** | 填報每日工項、查看自身紀錄、申請材料、試算薪資 |
| **ADMIN（管理者）** | 擁有 USER 的所有功能，另可確認回報、管理帳戶、查看統計與計算薪資 |

---

## 啟動系統

在終端機進入專案目錄後執行：

```bash
python app.py
```

接著在瀏覽器開啟：

```
http://127.0.0.1:5000
```

**首次使用前，先執行以下指令建立測試資料：**

```bash
python seed.py
```

這會建立 3 個測試帳號與 30 筆示範資料（執行一次即可，重複執行會清空資料庫）。

---

## 帳號說明

每個帳戶只需要三項資料：

| 項目 | 說明 |
|------|------|
| **帳戶名稱** | 顯示用名稱，允許中文，用於登入下拉選單 |
| **密碼** | 登入時輸入 |
| **帳戶類型** | USER 或 ADMIN |

**測試帳號（使用 `python seed.py` 建立）：**

| 帳戶名稱 | 密碼 | 角色 |
|---------|------|------|
| 張管理員 | admin123 | ADMIN |
| 陳小明 | user123 | USER |
| 李小華 | user123 | USER |

## 登入方式

1. 開啟 `http://127.0.0.1:5000`
2. 從下拉選單選擇自己的姓名
3. 輸入對應密碼
4. 點擊「登入」

> 密碼輸入框右側的眼睛圖示可切換顯示/隱藏密碼。

登入成功後：
- **USER** 會進入「回報頁面」
- **ADMIN** 會進入「Summary 頁面」

## 一般使用者（USER）功能

### 回報頁面

每日在此填報工項數量。

**填寫步驟：**

1. 確認或調整**日期**（預設為今日）
2. 在各工項欄位填入當日完成的只數（預設為 0，留空即代表 0）
3. 點擊「送出」
4. 系統會彈出確認框，顯示各項數值小計，確認無誤後點擊「確認送出」

**工項欄位說明（共 16 項，單位：只）：**

| 欄位名稱 | 說明 |
|---------|------|
| 直總-13 / 直總-20 / 直總-25 / 直總-40 | 直總工項，依管徑分類 |
| 間接-13 / 間接-20 / 間接-25 / 間接-40 | 間接工項，依管徑分類 |
| 直總—整組、拆泥、換由令(含表) | 直總特殊工項 |
| 間接—拆泥、換由令(含表) | 間接特殊工項 |
| 大改小(不含表) | 改管工項 |
| 原大改小(不含表) | 原改管工項 |
| 特殊 | 特殊工項 |
| 動員 | 動員工項 |
| 複查案 | 複查工項 |
| 清土 | 清土工項 |

> 同一天可多次送出回報，不限筆數。

---

### 歷史紀錄頁面

查看自己過去提交的所有回報。

**功能：**
- 可依日期範圍篩選
- 每筆回報可點擊鉛筆圖示**修改**，或垃圾桶圖示**刪除**
- 若修改已被 ADMIN 確認的回報，該筆狀態會自動重置為「未確認」，需 ADMIN 重新確認

> 所有修改與刪除操作都有二次確認對話框防止誤操作。

---

### 剩餘材料頁面

查看目前材料庫存，並提出領用申請。

**功能：**
1. 查看所有材料名稱、單位與剩餘數量（數量偏低時會顯示紅色/黃色警示）
2. 點擊「申請」，在彈出視窗中填入申請數量後送出
3. 頁面下方可查看自己所有申請紀錄的狀態（待審核 / 已核准 / 已駁回）

---

### 個人統計頁面

自行查看工項加總與試算薪資，無需等待 ADMIN 操作。

**功能：**
1. **工項加總**：選定日期範圍與確認狀態，查看各工項的只數合計
2. **薪資試算**：填入各工項的單價後，系統計算預估薪資

> **注意：** 此頁面的試算結果僅供個人參考，正式薪資以 ADMIN 在 Salary 頁面計算的結果為準。

---

### 設定頁面

修改自己的登入密碼。

**步驟：**
1. 輸入目前密碼
2. 輸入新密碼（至少 4 個字元）
3. 再次輸入新密碼確認
4. 點擊「更新密碼」

---

### 變動紀錄頁面

查看自己的所有操作歷史，包括回報新增、修改、刪除、材料申請等。

> 變動紀錄只能查看，不能修改或刪除。

---

## 管理者（ADMIN）功能

ADMIN 擁有 USER 的所有功能，並額外擁有以下管理功能。

### 確認頁面

處理待確認項目。

**功能一：確認回報**
- 列出所有員工尚未確認的回報
- 逐筆檢查後點擊「確認」按鈕（會有二次確認對話框）
- 確認後該筆回報才會納入 Salary 薪資計算

**功能二：審核材料申請**
- 列出所有待審核的材料申請
- 點擊「核准」：庫存自動扣減對應數量
- 點擊「駁回」：申請標記為駁回，庫存不變
- 兩者皆有二次確認對話框

---

### Summary 頁面

統計報表，依日期範圍與帳戶查看各工項的回報總量。

**篩選條件：**
- 開始日期 / 結束日期（必填）
- 帳戶（可選特定人員或「全部」）
- 確認狀態（全部 / 僅已確認 / 僅未確認）

**顯示結果：**
- 每列為一位員工，各欄為工項總數
- 最後一列為所有人的合計

---

### Salary 頁面

計算並輸出薪資明細。

**操作步驟：**
1. 選定計薪日期範圍
2. 在各工項欄位填入每只的計薪單價（NTD，可留 0 表示不計薪）
3. 點擊「計算薪資」
4. 查看頁面上的薪資明細表格
5. 可匯出為 **PDF** 或 **Excel (.xlsx)** 檔案

> **計薪規則：** 只計算 `is_confirmed = true`（已確認）的回報，未確認的回報不納入計算。

---

### 設定頁面（ADMIN 額外功能）

除了修改自己的密碼，ADMIN 還可以管理所有帳戶。

**帳戶管理功能：**

| 操作 | 說明 |
|------|------|
| 新增帳戶 | 填入帳戶名稱、密碼、帳戶類型（USER/ADMIN） |
| 修改名稱 | 修改任一帳戶的顯示名稱 |
| 重設密碼 | 直接設定任一帳戶的新密碼，無需輸入舊密碼 |
| 刪除帳戶 | 可選擇保留歷史資料（僅停用登入）或連帶刪除該帳戶所有回報與申請紀錄 |

> 所有帳戶操作均有二次確認對話框，且自動產生變動紀錄。

---

### 變動紀錄頁面（ADMIN 視角）

ADMIN 可查看**所有人**的完整操作歷史，包含帳戶管理、回報確認、材料審核等。

---

## 共用功能

### 側邊欄導覽

登入後左側顯示側邊欄，可快速切換頁面。不同角色看到的選單項目不同。

### 防呆機制

所有會異動資料的操作（儲存、修改、刪除、確認、核准、駁回⋯）均設有**二次確認對話框**，避免誤操作。

### 右上角

- 顯示目前登入的帳戶名稱與角色標籤
- 點擊「登出」可安全登出系統

---

## 注意事項

1. **薪資計算只納入「已確認」的回報**：若某日的回報尚未被 ADMIN 確認，該筆不計入薪資。
2. **修改已確認的回報會重置確認狀態**：員工修改後需 ADMIN 重新確認，才會重新納入薪資計算。
3. **變動紀錄不可刪除**：所有操作歷史永久保存，任何人（含 ADMIN）均不可修改或刪除。
4. **材料申請核准後即扣庫存**：核准後庫存數量立即扣減，請確認無誤再核准。
5. **個人統計薪資試算僅供參考**：正式薪資以 ADMIN 的 Salary 頁面結果為準。
