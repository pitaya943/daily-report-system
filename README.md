## 系統介紹

本系統供工程隊使用，主要功能包含：

- **員工**（USER）每天填寫當日工項施工數量
- **管理員**（ADMIN）確認回報、計算薪資、管理帳戶與材料

系統分為兩種角色：

| 角色 | 說明 |
|------|------|
| **USER** | 一般員工，可填寫回報、查詢歷史、申請材料、查看個人統計 |
| **ADMIN** | 管理員，擁有所有 USER 功能，額外可確認回報、計算薪資、管理帳戶與系統設定 |

## 登入與登出

### 登入

1. 開啟瀏覽器，輸入系統網址
2. 在登入頁面選擇你的**帳戶名稱**（下拉選單）
3. 輸入**密碼**
4. 點擊**登入**按鈕

> **注意**：若連續輸入錯誤密碼超過 **10 次**，系統會封鎖該 IP **1 分鐘**，請稍後再試。

> **Session 過期**：登入後若超過 **10 分鐘**沒有操作，系統會自動登出，需重新登入。

### 登出

點擊左側側欄底部的**「登出」**按鈕即可登出。

### 側欄收合

點擊頁面左上角的 ☰ 按鈕可收合/展開左側導覽列，收合後只顯示圖示，節省螢幕空間。瀏覽器會記住你的偏好設定。

## USER 功能說明

---

### 1. 回報頁面

**用途**：填寫今天施工的工項數量。

#### 如何填寫回報

1. 點擊左側選單「**回報**」
2. 頁面顯示今天的日期（不可修改）
3. 在各工項欄位輸入**數量**（只填有施工的項目，其他留空或填 0）
4. 確認後點擊**「送出回報」**

> **已送出可以修改嗎？**
> 可以。在 ADMIN **確認之前**，當天的回報可以重新填寫並送出，系統會更新數據（不會產生重複回報）。
> 一旦 ADMIN 確認後，**USER 無法再修改**該回報。

#### 工項欄位說明

| 欄位名稱 | 說明 |
|----------|------|
| 直總管 13mm / 20mm / 25mm / 40mm | 直埋總管各口徑 |
| 間接管 13mm / 20mm / 25mm / 40mm | 間接配管各口徑 |
| 原改 | 原有管路改管 |
| 換由令（直接/間接） | 換由令工項 |
| 換開關 13~25mm / 40mm | 換瓦斯開關 |
| 直總固拆 13~25mm / 40mm | 直總管固定拆除 |
| 間接固拆 13~25mm / 40mm | 間接管固定拆除 |
| 管修 | 管路修繕 |
| 動員 | 動員費 |
| 複查 | 複查工項 |
| 清積土 | 清除積土 |

### 2. 歷史紀錄

**用途**：查詢過去的回報記錄，並可修改或刪除未確認的回報。

#### 查詢記錄

1. 點擊左側選單「**歷史紀錄**」
2. 畫面預設顯示你所有的回報記錄（最新在前）
3. 可設定**開始日期**與**結束日期**篩選特定範圍，再點「**查詢**」
4. 點「**清除**」可移除篩選條件，顯示全部記錄

#### 回報狀態說明

| 狀態標籤 | 說明 |
|----------|------|
| 🟡 未確認 | 回報已送出，等待 ADMIN 確認 |
| 🟢 已確認 | ADMIN 已確認，薪資計算採用此筆資料 |
| 🔴 已駁回 | ADMIN 駁回，此筆不計入薪資 |

#### 修改回報

1. 找到要修改的回報列，點擊右方的 **✏️（鉛筆）** 圖示
2. 在彈出的修改視窗中調整各工項數量
3. 確認無誤後點「**儲存**」

> **限制**：已確認的回報，USER 無法修改（按鈕會呈灰色）。若需修改，請聯絡 ADMIN。

#### 刪除回報

1. 找到要刪除的回報列，點擊右方的 **🗑️（垃圾桶）** 圖示
2. 系統彈出確認視窗，確認後該筆回報刪除

> **限制**：已確認的回報，USER 無法刪除。若需刪除，請聯絡 ADMIN。

### 3. 剩餘材料

**用途**：查看目前材料庫存數量，並提出材料申請。

#### 查看庫存

1. 點擊左側選單「**剩餘材料**」
2. 頁面顯示所有材料項目、單位及目前剩餘數量
3. 剩餘數量顏色提示：
   - 🟢 綠色：庫存充足（> 20）
   - 🟡 黃色：庫存偏少（6 ~ 20）
   - 🔴 紅色：庫存不足（≤ 5）

#### 申請材料

1. 在想申請的材料列，點擊**「申請」**按鈕
2. 確認材料名稱與目前庫存
3. 輸入**申請數量**（不可超過庫存數量）
4. 點「**送出申請**」

#### 查看申請紀錄

頁面下方「**我的申請紀錄**」顯示你所有的申請及狀態：

| 狀態 | 說明 |
|------|------|
| 🟡 待審核 | 等待 ADMIN 審核 |
| 🟢 已核准 | ADMIN 已核准，庫存已扣除 |
| 🔴 已駁回 | ADMIN 駁回申請 |

#### 取消申請

僅限**待審核**狀態的申請可取消：
1. 在申請列右側點擊「**取消**」
2. 確認後申請取消

---

### 4. 變動紀錄

**用途**：查看系統中所有操作記錄（僅供查閱，無法修改）。

1. 點擊左側選單「**變動紀錄**」
2. 可依以下條件篩選：
   - **操作者**：選擇特定帳戶
   - **操作類型**：選擇特定動作（如「新增回報」、「確認回報」等）
   - **日期範圍**：設定起始與結束日期
3. 設定後點「**查詢**」，點「**清除**」還原

記錄欄位說明：

| 欄位 | 說明 |
|------|------|
| 時間 | 操作發生的日期時間 |
| 操作者 | 執行操作的帳戶名稱 |
| 操作類型 | 動作分類（如 REPORT_CREATE）|
| 描述 | 操作內容的文字說明 |

### 5. 個人統計

**用途**：查看自己在特定期間的工項施工數量統計，以及預估薪資試算。

頁面分為兩個獨立面板，可分別設定日期範圍查詢：

#### 工項統計面板

1. 設定「**統計起始**」與「**統計結束**」日期
2. 點擊「**查詢統計**」
3. 顯示該期間每個工項的總數量彙總

#### 薪資試算面板

1. 設定「**薪資計算起始**」與「**薪資計算結束**」日期
2. 勾選選項：
   - **扣除勞健保/稅務支出**：勾選後試算結果會扣除勞健保或稅務（依個人投保狀態）
3. 點擊「**試算**」
4. 顯示預估薪資明細（工項薪資、保留金、固定薪資、扣除項、最終金額）

> **說明**：試算結果僅供參考，實際薪資以 ADMIN 的薪資計算結果為準。試算只包含**已確認**的回報。

> **保留金**：系統會自動計算年度累計保留金（上限 5,000 元），達到上限後停止扣除。

### 6. 確認頁面

**用途**：確認或駁回員工回報、審核材料申請。

#### 日期篩選

頁面頂部有日期篩選列，預設顯示**最近 30 天**的待確認回報：
1. 設定「**起始日期**」與「**結束日期**」
2. 點「**篩選**」套用條件
3. 點「**重置**」回到預設 30 天範圍

#### 確認回報

「**待確認回報**」區塊顯示所有尚未確認的回報：

1. 可點「**詳情**」查看該回報的完整工項數量明細
2. 點「**✓ 確認**」→ 系統彈出確認視窗，確認後回報標記為「已確認」，納入薪資計算
3. 點「**✕ 駁回**」→ 系統彈出確認視窗，確認後回報標記為「已駁回」，不計入薪資

> **注意**：確認與駁回操作**無法撤銷**，請仔細核對後再操作。若需更改，ADMIN 可至「歷史紀錄」重新修改或刪除該筆回報。

#### 審核材料申請

「**待審核材料申請**」區塊顯示所有待審核的材料申請（每頁 20 筆）：

1. 確認申請者、材料名稱與申請數量
2. 點「**✓ 核准**」→ 庫存自動扣除對應數量，申請狀態更新為「已核准」
3. 點「**✕ 駁回**」→ 庫存不變，申請狀態更新為「已駁回」

> **注意**：若庫存不足（庫存 < 申請數量），系統會拒絕核准並顯示錯誤提示，請先至「設定 → 材料管理」補充庫存。

### 7. 薪資計算

**用途**：計算特定期間的員工薪資，並匯出相關文件。

#### 計算步驟

1. 點擊左側選單「**薪資計算**」
2. 設定計薪區間：
   - 方式一：點「**25 號發薪**」或「**10 號發薪**」快速按鈕，自動填入對應日期
   - 方式二：手動輸入「**開始日期**」與「**結束日期**」
3. **10 號發薪**：勾選「本次為 10 號發薪（含固定薪資與勞健保）」
4. 點「**計算薪資**」

#### 計算結果說明

結果頁面顯示每位在職員工的薪資明細：

| 欄位 | 說明 |
|------|------|
| 帳戶 | 員工名稱 |
| 工項薪資 | 各工項數量 × 單價的加總 |
| 保留金 | 本期扣除的保留金（年度累計上限 5,000 元）|
| 淨薪資 | 工項薪資 − 保留金 |
| 固定薪資 | 10 號發薪時才計入 |
| 勞健保扣除 | 10 號發薪且已投保才扣除 |
| 稅務支出 | 未投保且非免稅帳戶，= 工項薪資毛額 × 稅率% |
| **最終薪資** | **實際應付金額** |
| 銀行帳號 | 轉帳帳戶（僅轉帳方式顯示）|

#### 薪資計算規則

**10 號 vs 25 號發薪差異**：

| 項目 | 25 號發薪 | 10 號發薪 |
|------|-----------|-----------|
| 工項薪資計算 | ✓ | ✓ |
| 保留金扣除 | ✓ | ✓ |
| 固定薪資（加項）| ✗ | ✓ |
| 勞健保扣除 | ✗ | ✓ |
| 稅務支出 | 視情況 | 視情況 |

**稅務計算**：
- 已投保勞健保（`insurance_deduction > 0`）→ **不扣稅**
- 未投保且非免稅帳戶 → 扣除「工項薪資毛額 × 稅率%」
- 未投保且設定免稅 → **不扣稅**

#### 匯出文件

計算完成後，頁面上方提供三種匯出格式：

| 按鈕 | 匯出格式 | 內容 |
|------|----------|------|
| **匯出 Excel** | .xlsx | 每人一個工作表，含工項明細與薪資計算 |
| **匯出 PDF** | .pdf | 所有員工薪資彙整，支援中文列印 |
| **薪轉單（Word）** | .docx | 板信商業銀行薪資轉帳送件單格式，僅含轉帳帳戶員工 |

> **薪轉單說明**：僅包含發薪方式為「轉帳」且最終薪資 > 0 的員工，帳號格式自動調整為銀行送件格式。

### 9. 系統設定

**用途**：管理帳戶、工項單價、稅率、保留金費率及材料清單。

點擊左側選單「**設定**」進入。頁面分為多個區塊：

---

#### 9.1 帳戶管理

顯示所有帳戶清單（ADMIN 置頂，其餘依 ID 排序）。

##### 新增帳戶

1. 點擊「**新增帳戶**」按鈕
2. 填入：
   - **顯示名稱**：員工姓名（唯一，不可重複）
   - **初始密碼**：員工登入用密碼
   - **角色**：USER 或 ADMIN
   - **銀行帳號**（可選）：14 碼（3 碼分行 + 11 碼帳號）
   - **發薪方式**：現金或轉帳（選轉帳時需填銀行帳號）
3. 點「**新增**」

##### 重設密碼

在帳戶列找到對應帳戶：
1. 點「**密碼**」按鈕
2. 輸入新密碼（至少 6 位）
3. 點「**確認**」

> 員工亦可自行在設定頁修改自己的密碼。

##### 更改發薪方式

1. 點帳戶列的「**發薪**」按鈕
2. 選擇「現金」或「轉帳」
3. 若選「轉帳」但尚未設定銀行帳號，系統會提示先設定帳號

##### 設定銀行帳號

1. 點帳戶列的「**帳號**」按鈕
2. 輸入 14 碼銀行帳號（格式：3 碼分行 + 11 碼帳號，可含 `-` 分隔符）
3. 點「**儲存**」

> 銀行帳號在資料庫中以加密方式儲存，薪資計算時自動解密顯示。

##### 設定投保狀態

1. 點帳戶列的「**投保**」按鈕
2. 選擇：
   - **已投保**：輸入每期勞健保扣除金額（NTD）
   - **未投保需扣稅**：每期工項薪資毛額 × 稅率% 扣稅
   - **未投保免稅**：不扣勞健保也不扣稅
3. 點「**儲存**」

##### 設定固定薪資

1. 點帳戶列的「**固定薪**」按鈕
2. 輸入每月固定薪資金額（NTD），設定 0 表示無固定薪資
3. 固定薪資僅在**10 號發薪**時加入計算
4. 點「**儲存**」

##### 調整保留金費率

1. 點帳戶列的「**保留金**」按鈕
2. 可為每個工項欄位設定**客製費率（%）**
3. 若留空，該欄位使用全域費率（系統設定中的「保留金費率」）
4. 點「**儲存**」

##### 手動調整保留金累計

1. 點帳戶列的「**調整**」按鈕（保留金偏移量）
2. 輸入調整金額（可為負數，用於扣除或補償年度累計）
3. 此數值會直接加到年度保留金累計基準上

##### 停用帳戶

停用的帳戶無法登入，但資料保留：
1. 點帳戶列的「**停用**」按鈕
2. 確認後帳戶停用，名稱後方顯示「(停用)」

> 停用帳戶的歷史回報仍保留，但薪資計算不會包含已停用帳戶。

##### 復原帳戶

1. 找到已停用的帳戶（名稱後有「(停用)」）
2. 點「**復原**」按鈕，確認後恢復可登入狀態

##### 刪除帳戶

刪除分為兩種模式：

| 模式 | 說明 |
|------|------|
| **停用（保留資料）** | 帳戶無法登入，歷史回報與薪資紀錄保留 |
| **連帶刪除（永久）** | 帳戶及所有相關回報、材料申請、操作紀錄全數刪除，**無法還原** |

操作步驟：
1. 點帳戶列的「**刪除/停用**」按鈕
2. 在彈出視窗中選擇模式
3. 確認後執行

> ⚠️ **連帶刪除無法復原**，請謹慎操作。

---

#### 9.2 工項單價設定

設定每個工項的計薪單價（NTD/支）：

1. 在「**工項單價**」區塊找到對應工項
2. 修改單價數值
3. 點「**儲存工項單價**」

> 更新後下次薪資計算即使用新單價；快取最多延遲 5 分鐘（單 worker 無問題）。

---

#### 9.3 稅率設定

設定未投保員工的稅務扣除費率：

1. 在「**稅率設定**」區塊修改稅率（%）
2. 點「**儲存**」

> 目前預設稅率為 **3%**，計算基數為工項薪資毛額（不含固定薪資）。

---

#### 9.4 全域保留金費率

設定所有員工的預設保留金費率（未設定客製費率時使用）：

1. 在「**保留金費率**」區塊修改費率（%）
2. 點「**儲存**」

> 保留金年度上限固定為 **5,000 元**，與費率無關。個別帳戶可設定客製費率覆蓋此全域設定。

#### 9.5 材料管理

管理材料庫存清單：

##### 新增材料

1. 在材料區塊右上角點「**新增材料**」
2. 填入材料名稱、單位（如：支/個/包）、初始數量
3. 點「**新增**」

##### 調整庫存數量

1. 找到材料列，點「**✏️ 調整**」
2. 輸入新的庫存數量（直接覆蓋，非增量）
3. 點「**更新**」

##### 調整顯示順序

在材料列點 **↑** 或 **↓** 箭頭按鈕調整顯示順序。

##### 刪除材料

1. 點材料列的「**🗑️**」按鈕
2. 確認後刪除該材料（相關未審核的申請記錄也會一併刪除）

## 常見問題

**Q: 忘記密碼怎麼辦？**
A: 請聯絡 ADMIN，由管理員在「設定 → 帳戶管理」重設你的密碼。

**Q: 今天已經送出回報，能修改嗎？**
A: 可以，在 ADMIN 確認之前都可以重新填寫並送出，系統會自動更新（不會產生重複）。一旦 ADMIN 確認後就無法修改，請聯絡 ADMIN 協助處理。

**Q: 回報被駁回要怎麼辦？**
A: 聯絡 ADMIN 了解原因，ADMIN 可刪除已駁回的回報，讓你重新填寫並送出。

**Q: 薪資試算和 ADMIN 算的結果不一樣？**
A: 個人統計的試算使用**當下系統單價**計算，若 ADMIN 在計薪後調整了單價，結果可能不同。實際薪資以 ADMIN 計算並確認的版本為準。

**Q: 申請的材料一直顯示「待審核」？**
A: 需等待 ADMIN 在「確認頁面」審核。可詢問 ADMIN 審核進度。

**Q: 頁面顯示「Session 過期，請重新登入」？**
A: 超過 10 分鐘未操作會自動登出，重新登入即可，資料不會遺失。

**Q: ADMIN 如何設定銀行帳號的加密金鑰？**
A: 在 Railway Dashboard → Service → Variables 新增環境變數 `BANK_ENCRYPT_KEY`。金鑰生成指令：
```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```
設定後現有明文帳號需透過管理員後台路由 `/admin/migrate-bank-encrypt` 執行一次性加密遷移。
