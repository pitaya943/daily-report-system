## 系統介紹

本系統供工程隊使用，主要功能包含：

- **員工**（USER）每天填寫當日工項施工數量（支援**共同作業**，多人共同施工時由系統自動平分只數）
- **管理員**（ADMIN）確認回報、計算薪資、管理帳戶與材料

系統分為兩種角色：

| 角色 | 說明 |
|------|------|
| **USER** | 一般員工，可填寫回報、查詢歷史、申請材料、查看個人統計 |
| **ADMIN** | 管理員，擁有所有 USER 功能，額外可確認回報、計算薪資、管理帳戶與系統設定 |

系統分為**西區**與**南區**兩個施工區域，帳戶建立時由 ADMIN 指定。不同區域的工項欄位、計薪單價、保留金費率各自獨立設定。

## 登入與登出

### 登入

1. 開啟瀏覽器，輸入系統網址
2. 在登入頁面選擇你的**帳戶名稱**（下拉選單）
3. 輸入**密碼**
4. 點擊**登入**按鈕

> **注意**：若連續輸入錯誤密碼超過 **10 次**，系統會封鎖該 IP **1 分鐘**，請稍後再試。

> **Session 過期**：登入後若超過 **10 分鐘**沒有操作，系統會自動登出，需重新登入。

### 登出

點擊左側側欄底部的**「登出」**按鈕即可登出。

### 側欄收合

點擊頁面左上角的 ☰ 按鈕可收合/展開左側導覽列，收合後只顯示圖示，節省螢幕空間。瀏覽器會記住你的偏好設定。

### 1. 回報頁面

**用途**：填寫今天施工的工項數量，支援共同作業。

#### 如何填寫回報

1. 點擊左側選單「**回報**」
2. 頁面顯示今天的日期（不可修改）
3. 在各工項欄位輸入**數量**（只填有施工的項目，其他留空或填 0）
4. 若今日與其他人共同施工（共用同一張回報），使用「**共同作業人員**」功能新增協作者（見下方說明）
5. 確認後點擊**「送出回報」**

> **已送出可以修改嗎？**
> 可以。在 ADMIN **確認之前**，當天的回報可以重新填寫並送出，系統會更新數據（不會產生重複回報）。
> 一旦 ADMIN 確認後，**USER 無法再修改**該回報。

#### 共同作業功能

多位同區員工共同施工同一地點時，可使用共同作業功能，由系統**自動平分只數**（不需手動分配）：

1. 在回報頁面點擊「**+ 新增共同作業人員**」展開共作區塊
2. 在下拉選單選擇協作者（僅顯示與你**同區域**的啟用員工）
3. 最多可選 **6 位**共同作業者（加上你自己共最多 7 人）
4. 已選的協作者旁有「×」可移除
5. 填入當日工項總數量（視為全隊完成的合計量），點「**送出回報**」

> **只數分配規則**：系統使用 ceil/floor 演算法，確保所有人的分配量加總完全等於原始回報量（不會因四捨五入產生誤差）。例如 7 只 ÷ 3 人：提交者得 3 只，每位協作者各得 2 只，合計 7 只。

> **注意**：共同作業的協作者在**歷史紀錄**中也可以查看到這筆共作回報（以藍色底色標示），並在薪資計算中各自計入分配到的份額。

### 2. 歷史紀錄

**用途**：查詢過去的回報記錄，並可修改或刪除未確認的回報。

#### 查詢記錄

1. 點擊左側選單「**歷史紀錄**」
2. 畫面預設顯示你所有的回報記錄（最新在前），**包含你是協作者的共作回報**
3. 可設定**開始日期**與**結束日期**篩選特定範圍，再點「**查詢**」
4. 點「**清除**」可移除篩選條件，顯示全部記錄
5. 右上角「**匯出 Excel**」可下載目前篩選結果（不顯示載入畫面）

> **共作回報顯示**：你是協作者（非提交者）的共作回報，以**藍色底色**顯示，日期欄會標示「共作（XXX 回報）」，讓你清楚區分。

#### 回報狀態說明

| 狀態標籤 | 說明 |
|----------|------|
| 🟡 未確認 | 回報已送出，等待 ADMIN 確認 |
| 🟢 已確認 | ADMIN 已確認，薪資計算採用此筆資料 |
| 🔴 已駁回 | ADMIN 駁回，此筆不計入薪資 |

#### 修改回報

1. 找到要修改的回報列，點擊右方的 **✏️（鉛筆）** 圖示
2. 在彈出的修改視窗中調整各工項數量
3. 確認無誤後點「**儲存**」

> **限制**：已確認的回報，USER 無法修改（按鈕會呈灰色）。若需修改，請聯絡 ADMIN。

#### 刪除回報

1. 找到要刪除的回報列，點擊右方的 **🗑️（垃圾桶）** 圖示
2. 系統彈出確認視窗，確認後該筆回報刪除

> **限制**：已確認的回報，USER 無法刪除。若需刪除，請聯絡 ADMIN。

### 3. 材料庫存

**用途**：查看目前材料庫存數量，並提出材料申請。

#### 查看庫存

1. 點擊左側選單「**材料庫存**」
2. 頁面以**分頁標籤**方式顯示材料（最多 10 個分頁，由 ADMIN 設定名稱）
3. 每頁顯示欄位：**材料編號**、**材料名稱**、**規格**、**單位**、**庫存量**、**申請**
4. 庫存量顏色提示：
   - 🟢 綠色：庫存充足（> 5）
   - 🟡 黃色：庫存偏少（1 ~ 5）
   - 🔴 紅色：庫存為零（≤ 0）

#### 申請材料

1. 在想申請的材料列，點擊**「申請」**按鈕（庫存為零時按鈕呈灰色，無法點選）
2. 確認材料名稱、規格與目前庫存
3. 輸入**申請數量**（最少 1，最多 99，整數）
4. 可選填**備註**（最多 50 個字）
5. 點「**送出申請**」

#### 查看申請紀錄

頁面下方「**我的申請紀錄**」顯示你所有的申請及狀態：

| 狀態 | 說明 |
|------|------|
| 🟡 待審核 | 等待 ADMIN 審核 |
| 🟢 已核准 | ADMIN 已核准，庫存已扣除 |
| 🔴 已駁回 | ADMIN 駁回申請 |

#### 取消申請

僅限**待審核**狀態的申請可取消：
1. 在申請列右側點擊「**取消**」
2. 確認後申請取消

### 4. 變動紀錄

**用途**：查看系統中所有操作記錄（僅供查閱，無法修改）。

1. 點擊左側選單「**變動紀錄**」
2. 可依以下條件篩選：
   - **操作者**：選擇特定帳戶
   - **操作類型**：選擇特定動作（如「新增回報」、「確認回報」等）
   - **日期範圍**：設定起始與結束日期
3. 設定後點「**查詢**」，點「**清除**」還原

記錄欄位說明：

| 欄位 | 說明 |
|------|------|
| 時間 | 操作發生的日期時間 |
| 操作者 | 執行操作的帳戶名稱 |
| 操作類型 | 動作分類（如 REPORT_CREATE）|
| 描述 | 操作內容的文字說明 |

### 5. 個人統計

**用途**：查看自己在特定期間的工項施工數量統計，以及預估薪資試算。

頁面分為兩個獨立面板，可分別設定日期範圍查詢：

#### 工項統計面板

1. 設定「**統計起始**」與「**統計結束**」日期
2. 點擊「**查詢統計**」
3. 顯示該期間每個工項的總數量彙總

#### 薪資試算面板

1. 設定「**薪資計算起始**」與「**薪資計算結束**」日期
2. 勾選選項：
   - **扣除勞健保/稅務支出**：勾選後試算結果會扣除勞健保或稅務（依個人投保狀態）
3. 點擊「**試算**」
4. 顯示預估薪資明細（工項薪資、保留金、固定薪資、扣除項、最終金額）

> **說明**：試算結果僅供參考，實際薪資以 ADMIN 的薪資計算結果為準。試算只包含**已確認**的回報（含你是協作者的共作回報）。

> **保留金**：系統會自動計算年度累計保留金（上限 **60,000 元**），達到上限後停止扣除。費率依所屬區域（西區/南區）使用對應設定。

### 6. 確認頁面

**用途**：批次確認或駁回員工回報、批次審核材料申請。

#### 日期與區域篩選

頁面頂部有日期篩選列，預設顯示**最近 30 天**的待確認回報：
1. 設定「**起始日期**」與「**結束日期**」
2. 可選擇篩選**特定區域**（西區 / 南區 / 全部）
3. 點「**篩選**」套用條件
4. 點「**重置**」回到預設 30 天範圍

#### 批次確認/駁回回報

「**待確認回報**」區塊顯示所有尚未確認的回報，依西區/南區分組：

1. 勾選要處理的回報（可勾選單筆或使用「**全選**」checkbox 一次選取全部）
2. 若回報為共同作業，帳戶欄會顯示「**共 N 人**」badge
3. 可點「**詳情**」查看該回報的完整工項數量明細（含共同作業者名稱）
4. 確認勾選後，點 Card 右上角的**「批次確認」**或**「批次駁回」**按鈕
5. 系統彈出確認視窗，確認後一次處理所有勾選項目

> **注意**：確認與駁回操作**無法撤銷**，請仔細核對後再操作。若需更改，ADMIN 可至「歷史紀錄」重新修改或刪除該筆回報。

#### 批次審核材料申請

「**待審核材料申請**」區塊顯示所有待審核的材料申請：

1. 勾選要處理的申請（可使用「**全選**」一次選取全部）
2. 確認申請者、材料名稱、申請數量與備註
3. 點**「批次核准」**→ 勾選項目的庫存自動扣除，狀態更新為「已核准」
4. 點**「批次駁回」**→ 庫存不變，狀態更新為「已駁回」

> **注意**：若庫存不足，系統會拒絕核准並顯示錯誤提示。

### 7. 薪資計算

**用途**：計算特定期間的員工薪資，並匯出相關文件。

#### 計算步驟

1. 點擊左側選單「**薪資計算**」
2. 設定計薪區間：
   - 方式一：點「**25 號發薪**」或「**10 號發薪**」快速按鈕，自動填入對應日期
   - 方式二：手動輸入「**開始日期**」與「**結束日期**」
3. **10 號發薪**：勾選「本次為 10 號發薪（含固定薪資與勞健保）」
4. 點「**計算薪資**」

#### 計算結果說明

結果頁面顯示所有有已確認回報的員工薪資明細（**包含停用帳戶**）：

| 欄位 | 說明 |
|------|------|
| 帳戶 | 員工名稱（停用帳戶旁顯示「停用」標籤；名稱後顯示「西區」或「南區」badge）|
| 工項薪資 | 各工項數量 × 對應區域單價的加總（含共作分配到的份額）|
| 保留金 | 本期扣除的保留金（年度累計上限 **60,000 元**）|
| 淨薪資 | 工項薪資 − 保留金 |
| 固定薪資 | 10 號發薪時才計入（或設定每期發放的帳戶）|
| 勞健保扣除 | 10 號發薪且已投保才扣除 |
| 稅務支出 | 未投保且非免稅帳戶，= 工項薪資毛額 × 對應區域稅率% |
| **最終薪資** | **實際應付金額** |
| 銀行帳號 | 轉帳帳戶（僅轉帳方式顯示）|

#### 薪資計算規則

**10 號 vs 25 號發薪差異**：

| 項目 | 25 號發薪 | 10 號發薪 |
|------|-----------|-----------|
| 工項薪資計算 | ✓ | ✓ |
| 保留金扣除 | ✓ | ✓ |
| 固定薪資（加項）| ✗ | ✓ |
| 固定薪資（每期設定）| ✓ | ✓ |
| 勞健保扣除 | ✗ | ✓ |
| 稅務支出 | 視情況 | 視情況 |

**稅務計算**：
- 已投保勞健保（`insurance_deduction > 0`）→ **不扣稅**
- 未投保且非免稅帳戶 → 扣除「工項薪資毛額 × 稅率%」
- 未投保且設定免稅 → **不扣稅**

#### 匯出文件

計算完成後，頁面上方提供三種匯出格式：

| 按鈕 | 匯出格式 | 內容 |
|------|----------|------|
| **匯出 Excel** | .xlsx | 每人一個工作表，含工項明細與薪資計算 |
| **匯出 PDF** | .pdf | 所有員工薪資彙整，支援中文列印 |
| **薪轉單（Word）** | .docx | 板信商業銀行薪資轉帳送件單格式，僅含轉帳帳戶員工 |

> **薪轉單說明**：僅包含發薪方式為「轉帳」且最終薪資 > 0 的員工，帳號格式自動調整為銀行送件格式。

### 8. 統計報表

**用途**：查看跨帳戶的工項數量統計與彙總。

#### 查詢方式

1. 點擊左側選單「**統計報表**」
2. 設定「**開始日期**」與「**結束日期**」
3. 可選擇篩選**特定帳戶**、**區域**（西區/南區），或選「全部」
4. 點「**查詢**」

#### 結果顯示

- 每人的各工項數量彙總（**共作回報的只數依 ceil/floor 演算法分配到各人名下，加總不失真**）
- 頁面末端顯示全員合計
- 可匯出 **Excel** 或 **PDF** 格式（只數欄位顯示至小數後一位）

### 9. 系統設定

**用途**：管理帳戶、工項單價、稅率、保留金費率及材料庫存。

點擊左側選單「**設定**」進入。頁面分為多個區塊：

---

#### 9.1 帳戶管理

顯示所有帳戶清單（ADMIN 置頂，其餘依 ID 排序）。

##### 新增帳戶

1. 點擊「**新增帳戶**」按鈕
2. 填入：
   - **顯示名稱**：員工姓名（唯一，不可重複）
   - **初始密碼**：員工登入用密碼
   - **角色**：USER 或 ADMIN
   - **施工區域**：**西區** 或 **南區**（決定回報工項、計薪單價與保留金費率）
   - **銀行帳號**（可選）：14 碼（3 碼分行 + 11 碼帳號）
   - **發薪方式**：現金或轉帳（選轉帳時需填銀行帳號）
3. 點「**新增**」

> **區域說明**：帳戶建立後，登入時回報頁面自動顯示對應區域工項（西區 31 欄 / 南區 36 欄）；薪資計算也使用對應區域的單價與費率。區域設定後可由 ADMIN 在帳戶設定中修改。

##### 重設密碼

在帳戶列找到對應帳戶：
1. 點「**密碼**」按鈕
2. 輸入新密碼（至少 6 位）
3. 點「**確認**」

> 員工亦可自行在設定頁修改自己的密碼。

##### 更改發薪方式

1. 點帳戶列的「**發薪**」按鈕
2. 選擇「現金」或「轉帳」
3. 若選「轉帳」但尚未設定銀行帳號，系統會提示先設定帳號

##### 設定銀行帳號

1. 點帳戶列的「**帳號**」按鈕
2. 輸入 14 碼銀行帳號（格式：3 碼分行 + 11 碼帳號，可含 `-` 分隔符）
3. 點「**儲存**」

> 銀行帳號在資料庫中以加密方式儲存，薪資計算時自動解密顯示。

##### 設定投保狀態

1. 點帳戶列的「**投保**」按鈕
2. 選擇：
   - **已投保**：輸入每期勞健保扣除金額（NTD）
   - **未投保需扣稅**：每期工項薪資毛額 × 稅率% 扣稅
   - **未投保免稅**：不扣勞健保也不扣稅
3. 點「**儲存**」

##### 設定固定薪資

1. 點帳戶列的「**固定薪**」按鈕
2. 輸入固定薪資金額（NTD），設定 0 表示無固定薪資
3. 勾選「**每期發放**」：固定薪資**每期**皆發放（不受 10 號發薪限制）；不勾選則僅在 **10 號發薪**時加入計算
4. 點「**儲存**」

> 帳戶清單的固定薪資欄位會顯示 `每期` 或 `10號` badge，方便確認設定狀態。

##### 調整保留金費率

1. 點帳戶列的「**保留金**」按鈕
2. 可為每個工項欄位設定**客製費率（%）**
3. 若留空，該欄位使用全域費率（系統設定中的「保留金費率」）
4. 點「**儲存**」

##### 手動調整保留金累計

1. 點帳戶列的「**調整**」按鈕（保留金偏移量）
2. 輸入調整金額（可為負數，用於扣除或補償年度累計）
3. 此數值會直接加到年度保留金累計基準上

##### 停用帳戶

停用的帳戶無法登入，但資料保留：
1. 點帳戶列的「**停用**」按鈕
2. 確認後帳戶停用，名稱後方顯示「(停用)」

> 停用帳戶無法登入，但歷史回報仍保留。**已確認的回報依然納入薪資計算**（代表公司應支付的工作成果），薪資計算結果中會在名稱旁標示「停用」。

##### 復原帳戶

1. 找到已停用的帳戶（名稱後有「(停用)」）
2. 點「**復原**」按鈕，確認後恢復可登入狀態

##### 刪除帳戶

刪除分為兩種模式：

| 模式 | 說明 |
|------|------|
| **停用（保留資料）** | 帳戶無法登入，歷史回報與薪資紀錄保留 |
| **連帶刪除（永久）** | 帳戶及所有相關回報、材料申請、操作紀錄全數刪除，**無法還原** |

操作步驟：
1. 點帳戶列的「**刪除/停用**」按鈕
2. 在彈出視窗中選擇模式
3. 確認後執行

> ⚠️ **連帶刪除無法復原**，請謹慎操作。

#### 9.2 工項單價設定

工項單價分**西區**與**南區**兩套獨立設定：

1. 在「**西區工項單價**」或「**南區工項單價**」區塊找到對應工項
2. 修改單價數值
3. 點「**儲存西區工項單價**」或「**儲存南區工項單價**」

> 更新後下次薪資計算即使用新單價；快取最多延遲 5 分鐘。
> 南區若未設定某工項單價，自動沿用西區的同名欄位單價（fallback 機制）。

#### 9.3 稅率設定

稅率分**西區**與**南區**兩個獨立設定：

- **西區稅率**：在「**西區稅率設定**」修改，點「**儲存**」
- **南區稅率**：在「**南區稅率設定**」修改，點「**儲存**」

> 預設稅率均為 **3%**，計算基數為工項薪資毛額（不含固定薪資）。

---

#### 9.4 全域保留金費率

保留金費率分**西區**與**南區**兩個獨立設定：

- **西區保留金費率**：在「**西區保留金費率**」修改，點「**儲存**」
- **南區保留金費率**：在「**南區保留金費率**」修改，點「**儲存**」

> 保留金年度上限固定為 **60,000 元**，與費率無關。個別帳戶可設定客製費率覆蓋此全域設定。

#### 9.5 材料庫存管理

點擊左側選單「**材料庫存**」（ADMIN 版），提供完整庫存管理功能。

##### 分頁管理

材料可依用途分為最多 **10 個分頁**，方便分類管理：
1. 點擊「**管理分頁名稱**」
2. 填入各分頁名稱（留空的分頁會自動隱藏）
3. 點「**儲存**」

> 分頁 1 建議保留名稱（如「全部材料」），以防全部分頁消失。

##### 新增材料

1. 點「**新增材料**」按鈕
2. 填入材料編號（可選）、材料名稱（必填）、規格、單位（必填）、初始庫存量
3. 選擇所屬分頁
4. 點「**新增**」

##### 調整庫存數量

1. 找到材料列，點「**✏️ 調整**」
2. 可修改庫存量（直接覆蓋）與累計使用量
3. 點「**更新**」

> 實領量 = 累計使用量 + 庫存量，由系統自動計算。

##### 調整顯示順序

點材料列的 **↑** 或 **↓** 箭頭按鈕即時調整（AJAX，不需重新載入頁面）。

##### 隱藏/顯示材料

點材料列的 **👁（眼睛）** 按鈕即時切換：
- 隱藏後：ADMIN 頁面材料列呈半透明，顯示「已隱藏」badge；USER 頁面**不顯示**該材料
- 再次點擊恢復顯示

##### 移至其他分頁

在材料列點「**移至▾**」下拉選單，選擇目標分頁即可移動。

##### 刪除材料

1. 點材料列的「**🗑️**」按鈕
2. 確認後刪除該材料（相關未審核的申請記錄也會一併刪除）

##### 匯入 Excel（盤點比對）

上傳 Excel/CSV 盤點報告，系統自動比對 A 系統（資料庫）與 B 系統（Excel 檔案）的數量：

1. 點「**匯入 Excel**」按鈕
2. 選擇 `.xlsx` 或 `.csv` 檔案（欄位需含「材料編號」與「實領量」）
3. 點「**開始比對**」

**比對結果**：
- **正常**：B 系統實領量 ≥ A 系統且 A 系統內部一致 → 自動更新庫存
- **異常**：數量不符或 A 系統內部矛盾 → 材料移入**暫存區**待人工審查

成功匯入後，頁面會顯示「**已對比：檔名**」標籤；重置庫存後標籤消失。

##### 暫存區（批次解決）

匯入後有數量異常的材料會進入暫存區。操作方式：
1. 在每列選擇「**信任A**」（保留 A 系統累計使用量）或「**信任B**」（採用 Excel 數值）
   - 系統預設：A 系統有誤 → 預選「信任B」；B 系統有誤或不明 → 預選「信任A」
2. 可點 Card 頂部的「**全部設為信任A**」或「**全部設為信任B**」快速設定
3. 勾選要處理的列（或「全選/取消」）
4. 點「**儲存選取項目**」一次處理全部勾選

##### 匯出 Excel

點「**匯出 Excel**」（不顯示載入畫面）下載目前所有非暫存區材料的庫存清單。

##### 重置庫存

點「**重置庫存**」→ 確認後，所有材料庫存歸零並恢復預設 94 筆清單，「已對比」標籤也會一併清除。

> ⚠️ 重置後現有庫存量全部歸零，此操作無法撤銷。

### 10. 流水帳

**用途**：記錄公司收入與支出，支援憑證（發票/收據）上傳。

#### 查看記錄

1. 點擊左側選單「**流水帳**」
2. 頁面頂部顯示篩選期間的合計（收入/支出/淨額）
3. 可依以下條件篩選：
   - **日期範圍**：設定起始與結束日期
   - **類型**：全部 / 收入 / 支出
4. 點「**篩選**」套用，點「**清除**」重置

#### 新增記錄

1. 點擊「**新增記錄**」按鈕
2. 填入：
   - **日期**：記帳日期
   - **類型**：收入或支出
   - **金額**（NTD）
   - **描述**：說明文字
   - **類別**（可選）：如材料費、人工費、雜支等
   - **備註**（可選）
   - **支出者**（可選）：若由員工墊付，選擇對應帳戶
   - **憑證**（可選）：上傳發票或收據（PDF/圖片，最大 10MB）
3. 點「**新增**」

#### 下載憑證

在記錄列點擊「**查看憑證**」，系統自動產生限時下載連結。

#### 沖銷

若記錄為員工墊付，確認還款後點「**沖銷**」，系統記錄沖銷操作。

> **注意**：流水帳所有操作均會記錄於「變動紀錄」。

### 11. 日月報檔案庫

**用途**：查看、下載或手動生成已存儲的日報與月報 Excel 檔案。

#### 自動生成排程

| 類型 | 觸發時間 | 內容 |

在記錄列點「**下載**」，系統產生限時連結，瀏覽器直接下載 Excel 檔案。

點「**🗑️**」刪除指定記錄，雲端儲存上的檔案也會一併移除。

## 常見問題

**Q: 忘記密碼怎麼辦？**
A: 請聯絡 ADMIN，由管理員在「設定 → 帳戶管理」重設你的密碼。

**Q: 今天已經送出回報，能修改嗎？**
A: 可以，在 ADMIN 確認之前都可以重新填寫並送出，系統會自動更新（不會產生重複）。一旦 ADMIN 確認後就無法修改，請聯絡 ADMIN 協助處理。

**Q: 回報被駁回要怎麼辦？**
A: 聯絡 ADMIN 了解原因，ADMIN 可刪除已駁回的回報，讓你重新填寫並送出。

**Q: 薪資試算和 ADMIN 算的結果不一樣？**
A: 個人統計的試算使用**當下系統單價**計算，若 ADMIN 在計薪後調整了單價，結果可能不同。實際薪資以 ADMIN 計算並確認的版本為準。

**Q: 如何確認我是否有共同作業的回報？**
A: 至「歷史紀錄」查詢，非自己提交的共作回報會以**藍色底色**顯示，並在日期欄標示「共作（XXX 回報）」。共作薪資份額已自動計入你的薪資計算中。

**Q: 申請的材料一直顯示「待審核」？**
A: 需等待 ADMIN 在「確認頁面」審核。可詢問 ADMIN 審核進度。

**Q: 頁面顯示「Session 過期，請重新登入」？**
A: 超過 10 分鐘未操作會自動登出，重新登入即可，資料不會遺失。

**Q: 材料庫存頁面看不到某些材料？**
A: 該材料可能已被 ADMIN 設定為隱藏（管理用，不影響庫存數量）。若有需要，請聯絡 ADMIN 顯示該材料。

**Q: ADMIN 如何設定銀行帳號的加密金鑰？**
A: 在 Railway Dashboard → Service → Variables 新增環境變數 `BANK_ENCRYPT_KEY`。金鑰生成指令：
```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```
設定後現有明文帳號需透過管理員後台路由 `/admin/migrate-bank-encrypt` 執行一次性加密遷移。
