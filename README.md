## 系統簡介

員工日報回報系統讓員工每日記錄各類工項數量，管理者可進行確認、統計與薪資計算。系統分為兩個角色：

| 角色 | 說明 |
|------|------|
| **USER（一般使用者）** | 填報每日工項、查看自身紀錄、申請材料、試算薪資、查看個人統計 |
| **ADMIN（管理者）** | 擁有 USER 的所有功能，另可確認回報、管理帳戶、查看全體統計、計算薪資 |

---

## 存取方式

### 線上版（正式環境）

直接開啟 Railway 提供的網址，無需安裝任何軟體。

### 本地開發版

```bash
# 首次使用：建立測試資料
python seed.py

# 啟動伺服器
python app.py
```

接著在瀏覽器開啟：`http://127.0.0.1:5000`

> `python seed.py` 會建立 3 個測試帳號與 30 筆示範資料。重複執行會清空並重建資料庫。

---

## 帳號說明

每個帳戶包含以下資料：

| 項目 | 說明 |
|------|------|
| **帳戶名稱** | 顯示用名稱，允許中文，用於登入下拉選單 |
| **密碼** | 登入時輸入（至少 4 個字元） |
| **帳戶類型** | USER 或 ADMIN |
| **發薪方式** | 領現（CASH）或轉帳（TRANSFER），由 ADMIN 設定 |

**測試帳號（執行 `python seed.py` 後建立）：**

| 帳戶名稱 | 密碼 | 角色 | 發薪方式 |
|---------|------|------|---------|
| 張管理員 | admin123 | ADMIN | 轉帳 |
| 陳小明 | user123 | USER | 轉帳 |
| 李小華 | user123 | USER | 領現 |

## 登入方式

1. 開啟系統網址
2. 從下拉選單選擇自己的姓名
3. 輸入對應密碼
4. 點擊「登入」

> 密碼輸入框右側的眼睛圖示可切換顯示/隱藏密碼。

登入成功後：
- **USER** 會進入「回報頁面」
- **ADMIN** 會進入「Summary 頁面」

## 一般使用者（USER）功能

### 回報頁面

每日在此填報工項數量。

**填寫步驟：**

1. 確認或調整**日期**（預設為今日）
2. 在各工項欄位填入當日完成的只數（預設為 0）
3. 點擊「送出」
4. 系統彈出確認框，顯示各項數值，確認無誤後點擊「確認送出」

**工項欄位（共 21 項，單位：只）：**

| 類別 | 欄位 |
|------|------|
| 直總類 | 直總-13 / 直總-20 / 直總-25 / 直總-40 |
| 間接類 | 間接-13 / 間接-20 / 間接-25 / 間接-40 |
| 其他工項 | 原改、直總-換由令(含表)-13~25、間接-換由令(含表)-13~25、13~25換開關(含表)、40換開關(含表)、直總-13~25固拆(含表)、直總-40固拆(含表)、間接-13~25固拆(含表)、間接-40固拆(含表)、管修(提高)、動員、複查案/9年表、清積土 |

> 同一天可多次送出回報，不限筆數。

---

### 歷史紀錄頁面

查看自己過去提交的所有回報。

- 可依日期範圍篩選
- 每筆回報可點擊鉛筆圖示**修改**，或垃圾桶圖示**刪除**
- 若修改已被 ADMIN 確認的回報，該筆狀態會自動重置為「未確認」，需 ADMIN 重新確認

> 所有修改與刪除操作都有二次確認對話框。

---

### 剩餘材料頁面

查看目前材料庫存，並提出領用申請。

1. 查看所有材料名稱、單位與剩餘數量（數量偏低時顯示紅色/橘色警示）
2. 點擊「申請」，填入申請數量後送出
3. 頁面下方查看自己所有申請的狀態（待審核 / 已核准 / 已駁回）

---

### 個人統計頁面

自行查看工項加總與試算薪資，無需等待 ADMIN 操作。

**今年度累積保留金**：頁面頂端顯示本年度（已確認回報）累積的保留金總額。

**功能一：工項加總**
- 選定日期範圍與確認狀態，查看各工項的只數合計
- 下方顯示「本期保留金」小計

**功能二：薪資試算**
- 填入各工項的單價後，系統計算預估薪資
- 顯示：計薪小計 → 保留金扣除 → **試算實領金額**

> **注意：** 此頁面的試算結果僅供個人參考，正式薪資以 ADMIN 在 Salary 頁面計算的結果為準。

---

### 設定頁面

修改自己的登入密碼。

1. 輸入目前密碼
2. 輸入新密碼（至少 4 個字元）
3. 再次輸入新密碼確認
4. 點擊「更新密碼」

---

### 變動紀錄頁面

查看自己的所有操作歷史（回報新增/修改/刪除、材料申請等）。可依日期範圍與操作類型篩選。

> 變動紀錄只能查看，不能修改或刪除。

---

## 管理者（ADMIN）功能

ADMIN 擁有 USER 的所有功能，並額外擁有以下管理功能。

### 確認頁面

**功能一：確認回報**
- 列出所有員工尚未確認的回報
- 逐筆檢查後點擊「確認」（有二次確認對話框）
- 確認後該筆回報才會納入 Salary 薪資計算

**功能二：審核材料申請**
- 列出所有待審核的材料申請
- 點擊「核准」：庫存自動扣減對應數量
- 點擊「駁回」：申請標記為駁回，庫存不變

---

### Summary 頁面

統計報表，依日期範圍與帳戶查看各工項的回報總量。

- 篩選條件：開始/結束日期、帳戶（全部或特定）、確認狀態
- 顯示每位員工各工項只數加總，最後一列為所有人合計

---

### Salary 頁面

計算並輸出薪資明細（僅計算已確認的回報）。

**操作步驟：**
1. 選定計薪日期範圍
2. 填入各工項的計薪單價（預設帶入系統預設單價）
3. 點擊「計算薪資」
4. 查看薪資明細

**計算結果顯示：**

每位帳戶：
- 計薪小計（稅前）
- 本期保留金（扣除）
- **本期實領金額**（= 計薪小計 − 保留金）
- 今年度累積保留金

整體發放總覽：
- 轉帳薪資總額
- 提現薪資總額
- 提現面額配置（最少張數：1000 / 500 / 100 / 50 / 10 / 5 / 1 NTD）

**匯出：** 可匯出為 **PDF** 或 **Excel (.xlsx)**，內含完整的薪資明細、保留金、發薪方式與面額配置。

---

### 設定頁面（ADMIN 額外功能）

除了修改自己的密碼，ADMIN 還可以：

**帳戶管理：**

| 操作 | 說明 |
|------|------|
| 新增帳戶 | 填入帳戶名稱、密碼、帳戶類型、發薪方式 |
| 修改名稱 | 修改任一帳戶的顯示名稱 |
| 修改發薪方式 | 切換領現（CASH）/ 轉帳（TRANSFER） |
| 重設密碼 | 直接設定任一帳戶的新密碼 |
| 刪除帳戶 | 選擇保留歷史資料（停用）或連帶刪除所有資料 |

**保留金費率設定：**
- 調整每只直總/間接工項的保留金扣取金額（預設 20 NTD/只）
- 修改即時生效，影響後續所有薪資計算

---

### 變動紀錄頁面（ADMIN 視角）

ADMIN 可查看**所有人**的完整操作歷史，支援以下篩選：
- 日期範圍
- **操作者**（下拉選單，選特定帳戶或全部）
- 操作類型

## 共用功能

### 側邊欄導覽

登入後左側顯示側邊欄，可快速切換頁面。不同角色看到的選單項目不同。

### 防呆機制

所有會異動資料的操作（儲存、修改、刪除、確認、核准、駁回）均設有**二次確認對話框**，避免誤操作。

### 右上角

- 顯示目前登入的帳戶名稱與角色標籤（ADMIN 紅色、USER 藍色）
- 點擊「登出」可安全登出系統

---

## 注意事項

1. **薪資計算只納入「已確認」的回報**：回報若尚未被 ADMIN 確認，不計入薪資。
2. **修改已確認的回報會重置確認狀態**：修改後需 ADMIN 重新確認，才會重新納入薪資計算。
3. **保留金會從薪資中扣除**：實領金額 = 計薪小計 − 保留金。保留金年底自然歸零，次年重新累計。
4. **變動紀錄不可刪除**：所有操作歷史永久保存，任何人（含 ADMIN）均不可修改或刪除。
5. **材料申請核准後即扣庫存**：核准後庫存數量立即扣減，請確認無誤再核准。
6. **個人統計薪資試算僅供參考**：正式薪資以 ADMIN 的 Salary 頁面結果為準。
7. **密碼含特殊字元的注意事項**：若密碼包含 `@` 符號，在設定 `DATABASE_URL` 環境變數時，`@` 需編碼為 `%40`。
